# Sistema de Controle de Alunos

## Atividade prática (2º tempo)

### 01. Quem poderá usar o sistema?

O sistema poderá ser utilizado por:
- Professores
- Diretores
- Coordenadores
- Secretários

Cada um terá acesso às funções de acordo com sua função na escola.

### 02. Cite 3 requisitos funcionais (o que o sistema deve fazer).

- Cadastrar alunos no sistema.
- Registrar notas e frequência dos alunos.
- Consultar e atualizar os dados dos alunos.

### 03. Cite 2 requisitos não funcionais (como o sistema deve funcionar).

- O sistema deve ser seguro, permitindo acesso apenas a usuários autorizados.
- O sistema deve ser rápido e estar disponível durante o horário de funcionamento da escola.

### 04. Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.

Porque isso ajuda a entender o que o cliente precisa, evita erros durante o desenvolvimento e garante que o sistema atenda às necessidades da escola.
